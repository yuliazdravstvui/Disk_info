# Disk Info — Анализ хранилища

Кроссплатформенное приложение для анализа использования дискового пространства.  
Показывает общий объём, занятое и свободное место на всех дисках с визуальным индикатором.

- Поддерживает Windows и Linux 
- Веб-интерфейс на Flask 
- Автоматическое определение всех подключенных дисков
- Цветная шкала заполнения в процентах

 Стек

- Python 3
- Библиотеки: os, shutil
- Flask (веб-версия)
- HTML / CSS (адаптивный интерфейс)


## Структура проекта
disk_info/  
├── app/  
│ ├── templates/  
│ │ └── index.html  веб-интерфейс  
│ ├── init.py  инициализация Flask  
│ ├── disk_utils.py  логика работы с дисками  
│ └── routes.py  маршруты  
├── run.py  точка входа для веб-версии  
├── main.py консольная версия  
└── README.md  описание проекта

python run.py
http://127.0.0.1:5000
